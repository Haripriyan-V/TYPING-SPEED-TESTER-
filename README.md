## 📌 Project Overview

The **Typing Speed Tester** is a browser-based application designed to help users measure their typing performance.

When the user starts the test, the application randomly selects a sentence from a predefined collection. The user then types the displayed sentence as quickly and accurately as possible.

After pressing **Enter**, the application calculates and displays:

- ⏱️ Time taken
- 📄 Words Per Minute (WPM)
- ✅ Typing accuracy

The project provides a simple and clean interface that can be used for practicing and improving typing skills.

---

## ✨ Features

### 🎯 Random Typing Sentence
A sentence is randomly selected from a predefined list whenever a new test starts.

### ⏱️ Time Measurement
The application records the time taken by the user to complete the typing test.

### 📄 Words Per Minute (WPM)
Typing speed is calculated based on the number of words typed and the time taken.

### ✅ Accuracy Calculation
The application compares the typed words with the original sentence and calculates the percentage of correctly typed words.

### 🔄 Reset Test
Users can reset the test after viewing their results and start a new typing session.

### ⚡ Instant Results
Results are displayed immediately after the user presses the **Enter** key.

### 📱 Simple Responsive Layout
The interface uses a simple layout that works within a browser window and adapts to different screen sizes.
